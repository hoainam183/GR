    \Large{\textbf{ABSTRACT}}\\
\end{center}
\vspace{1cm}
This thesis focuses on researching and developing a RAG (Retrieval-Augmented Generation) Chatbot system to support students in Q\&A about training regulations at Hanoi University of Science and Technology. The system allows students to ask questions in natural language and receive accurate answers with specific citations from regulatory documents.

The system is built on a complete RAG architecture, including: multi-modal PDF processing (Docling, PyMuPDF4LLM, olmOCR), legal text chunking following Article-Clause structure, embedding with E5 Multilingual model (1024 dimensions), vector storage using FAISS, and answer generation using Gemini 2.5 Flash. The backend is developed with FastAPI and the frontend uses React 18 with TypeScript.

The input data includes 16 training regulation documents from HUST, processed into 1,247 chunks stored in the vector store. The system achieves Vietnamese text processing accuracy of 99.5\%+ and response time of 2-4 seconds per query.
